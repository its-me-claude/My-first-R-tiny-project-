# Analysis of Student Academic Performance

## Project Overview

This is a tiny R project for analyzing student academic performance using a sample student dataset.

The project uses R Markdown to import, inspect, analyze, and visualize student academic data.

## Objectives

- Import the student dataset into R.
- Inspect the structure and contents of the data.
- Check for missing values.
- Calculate descriptive statistics.
- Analyze student performance based on marks.
- Analyze attendance and academic performance.
- Compare results by gender where applicable.
- Create visualizations to understand the data.

## Project Files

- `README.md` — Project description and instructions
- `Student_Academic_Performance_Tiny_Project.Rmd` — Main R Markdown source code
- `student_data_tiny_project.csv` — Dataset used by the project

## Technologies Used

- R
- R Markdown
- RStudio
- CSV dataset

## How to Run

1. Install R and RStudio.
2. Download or clone this repository.
3. Keep the `.Rmd` file and `.csv` dataset in the same folder.
4. Open `Student_Academic_Performance_Tiny_Project.Rmd` in RStudio.
5. Run the code or click **Knit** to generate the analysis report.

## Important

The CSV dataset should remain in the same project directory as the R Markdown file unless the file path in the R code is changed.

## Project Output

The project produces analysis and visualizations related to student academic performance.
